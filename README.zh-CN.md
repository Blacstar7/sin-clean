# Sin Clean（净尘）

一款注重隐私的原生 macOS 磁盘清理工具：全部处理在本机完成，绝不上传任何文件内容。

[English](README.md)

## 功能

- **Mac 状态** —— 系统健康一览仪表盘
- **空间清理** —— 可清理项目扫描，以及统一的**空间分析**工作台：左栏选范围、发起扫描，右区呈现结果、诊断与历史；任意窗口大小下扫描按钮始终可达
- **深度卸载** —— 连带关联文件检测的应用卸载，全程留证
- **设置** —— 偏好、权限与手动检查更新

## 原则

1. 仅本机处理——任何文件内容与名称都不离开你的 Mac
2. 只读优先——一切破坏性操作均须逐项明确确认
3. 移入废纸篓而非直接删除——可恢复
4. 签名加公证——Developer ID 签名、公证构建
5. 更新可验——更新包经 Ed25519 签名校验

## 构建

需要 macOS 14.0+ 与完整版 Xcode。

```bash
xcodebuild -project SinClean.xcodeproj -scheme SinClean build
```

## 更新

Sin Clean 仅在你主动要求时检查更新（设置 → 关于 → 检查更新）。更新清单经 Ed25519 签名，安装前逐包校验。
